# 徐海差旅助手

面向学院教职工的出差申请、差旅报销填表工具。选择表单、导入材料、自动填写、核对修改并打印。当前免费开放，无需注册或登录。

本系统由计算机系510工作室开发运维。指导老师：杨磊。

## 功能

- 两张独立表单：教职工出差申请表（A4 纵向）、差旅费报销单（A4 横向）。各自管理材料，上传只识别，点击“填写当前表单”才填表。
- 支持 PDF、图片、DOCX、UTF-8 文本；可选 DeepSeek 或 PaddleOCR 识别。单文件20MB、30页，每条记录最多30份材料。
- 自动保存、失败重试、本地未保存草稿恢复；服务器确认全部修改后才显示“已保存”。点击保存状态可重试，联网后也会重试。
- 浏览器会话恢复；个人信息设置内可保存/导入“记录找回文件”，换浏览器后可找回同一服务中的记录。找回文件包含访问凭证，请自行保管。
- 人工修改与人工清空不会被 AI 覆盖。材料来源、估算时间和异常金额可核对；原件可查看、重试识别或移除。
- 桌面和手机布局、整页缩放、打印及另存 PDF；学院院徽、标签页图标和510工作室署名。

## 本地运行

使用 Python 3.13。在本仓库目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.lock
Copy-Item .env.example .env
# 编辑 .env，填写服务端 API 密钥
.\start.ps1
```

访问 http://127.0.0.1:8000 。Linux/macOS 可使用 `.venv/bin/python -m uvicorn server.app:app --host 127.0.0.1 --port 8000 --workers 1`。

已有 `.env` 时不要覆盖。环境变量优先于 `.env`；旧本地工作目录的上级 `deepseek.txt` 仍兼容读取，独立克隆仓库只需配置 `.env`。运行时无需 Node、Word 或浏览器自动化工具。

## 金额与补助

- 每天补助180元。无会务费/培训费时，出发日到返回日全部计算：9月11日至13日为3天、540元。有费用时只计首尾两个日期；同日往返只算1天。
- 报销材料面板可以修改“是否实际收取会务费或培训费”。若 AI 误判，选择“否”并清零误填费用即可恢复全程补助。仍有正数费用时按有费用计算并提示冲突。
- 一张往返票只有总额2160元时，去程和返程各1080元；程序按分处理尾差。票面明确列出分段价格时按明细填入。不增加票价说明小字。
- 交通票据总额必须与识别文本中的明确合计一致；不一致、缺失或多种合计无法确定时拦截自动登记。金额核对依赖识别文本，仍需核对原件，不能等同于税务验真。人工改价导致分段合计与原票不符时提示核对。
- 缺失飞机或火车时刻可以推算，保留估算依据，票面及人工值优先；推测内容在打印时注明。

## 数据保存

数据默认位于 `.runtime`，可通过 `TRAVEL_DATA_DIR` 指定固定目录；包含 SQLite 数据库、上传原件与备份。新原件使用相对路径，旧绝对路径按原件布局兼容解析，支持整个数据目录迁移。

默认每天生成一次数据库及附件的完整备份，保留最近7份，位于数据目录 `backups`。备份失败写入服务日志。请将备份同步到服务器以外的位置，并定期演练恢复。同盘备份不能防止整台服务器或磁盘损坏。

清除浏览器存储前先保存找回文件；没有账号体系，既没有 Cookie、恢复标识，也没有找回文件时，无法自行认领旧记录。共享电脑会沿用当前浏览器的记录空间。找回文件只用于恢复身份，不包含票据，不替代服务器备份。

## 服务器部署

详见 [部署与备份](docs/deployment.md)。提供 Dockerfile、Compose、Nginx 反向代理片段、健康检查、日志轮转及数据卷配置。必须单实例、单 worker；启动锁会拒绝第二个进程使用同一数据目录。

生产环境使用 HTTPS，并启用 `TRAVEL_COOKIE_SECURE=true`。当前按产品决定不设置登录或收费额度。

## 测试

```powershell
.venv\Scripts\python -m pip install -r requirements-dev.lock
.venv\Scripts\python -m pytest -q tests
node --test tests/*.test.mjs
.venv\Scripts\python -m pip_audit -r requirements.lock
```

测试使用合成材料、临时数据库和模拟模型，不需要真实发票或 API 密钥，不产生模型费用。Node 只用于前端逻辑测试。GitHub Actions 在 Linux 上执行同样的基础检查。

## 目录

- `server/`：API、表单规则、AI 工具、识别、存储、备份与维护命令。
- `static/`：网页、样式和已生成的院徽及工作室图片；使用系统字体。
- `skills/`：填表提示词。
- `tests/`：可独立运行的回归测试。
- `deploy/`、`docs/`：服务器配置与说明。

密钥、运行数据、日志、找回文件和真实票据不进入 Git。旧原始资料、字体及一次性开发脚本已保留在本地归档中，不属于发布内容。

## 材料处理说明

选择识别服务后，PDF/图片会发送至该服务；自动填写会把识别文字发送给配置的模型服务。Word/文本先本地提取。系统用于辅助填写，提交前由使用者核对原件、金额、日期和学校要求。院徽、工作室标识及学校表单用于本项目展示，不作为通用素材授权声明。
