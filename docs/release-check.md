# 2026-09-20 修复与发布检查

本版按产品决定保持免费、免登录，不加入教师账号或用户调用额度限制。

已处理：

- 连续编辑提前显示已保存：用保存队列跟踪每个字段版本，服务器确认后才移除草稿；失败保留、可点击重试、联网重试与刷新恢复。
- 发票总额错误：交通票据登记核对 OCR 中明确的价税合计；税前小计不能替代总额。含糊或冲突时不自动写入。只有总额时均分，有分段价时支持明细；人工修改导致金额不符时提示核对。
- 补助误判无法纠正：新增实际收费选择，人工选择受保护，正数费用与“未收费”冲突时有提示。
- 原件迁移：新路径相对保存，兼容原 Windows 路径在新数据目录读取、重试和删除。
- 多 worker 干扰：增加操作系统级数据目录锁，拒绝第二个实例误恢复正在运行的任务。
- 并发上传：数量、去重和运行状态在写事务内复核；失败清理新暂存文件。
- 上传边界：限制请求体、Word 解压体积和压缩比、图片像素及 PDF 图片规模；不存在的重试文件返回404。
- 数据恢复：提供会话找回文件、每日数据库及附件备份、停止服务后的备份命令与恢复到新目录的命令。
- 更新与资源：HTML/静态资源重新校验缓存，关键资源更新版本；空闲轮询降低频率。

发布目录仅包含应用、合成测试、配置和文档。原发票、密钥、数据库、日志、商业字体原文件、旧脚本和旧浏览器测试留在本地归档或原资料目录。字体改用系统字体。依赖安装于独立虚拟环境并锁定版本，提供 Linux CI、Docker 构建、单 worker Compose、Nginx 片段和日志轮转。

本地验证：Python 回归、Node 保存与会话测试、依赖已知漏洞扫描；浏览器实际验证连续编辑后刷新、收费/不收费两种补助及390px手机材料面板。实际服务已生成首份自动备份。

本次未调用付费模型重新跑真实票据全流程。OCR/模型仍可能读错原件或无法识别复杂版式；程序对识别文本的核对不等于票据验真。Linux 构建和回归交由 GitHub Actions 验证；本机 Docker 引擎未运行。实际服务器部署、域名证书及服务器上的验收还需按部署文档执行。
